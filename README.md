# 教務・学生生活ハンドブック Web版プロトタイプ

## ファイル
- `index.html` — 本文
- `handbook.css` — `.hb-app` 配下にスコープしたスタイル
- `handbook.js` — 言語切替、目次生成、全文検索、現在位置表示
- `assets/` — 原版PDFから抽出・レンダリングした図版

## プロトタイプの考え方
- 第1〜5章の本文は、令和8年度納品PDFを基礎にHTMLとして再構成しています。
- 日本語／英語を同一ページ内で切り替えます（第5章は原版どおり日本語のみ）。
- 固定ページ番号 `(P.xx)` はWeb版では除去しています。
- Appendix・様式類はPDFのままカードリンクにしています。
- CSSクラスは `hb-` 接頭辞で衝突を避けています。JAIST公式HPへ組み込む際は、既存ヘッダー・パンくず等と重複する部分を削って使用する想定です。

## 注意
これは情報設計・操作性を確認するためのプロトタイプです。公開前には、各所管部署による本文確認、リンク先の実URLへの置換、アクセシビリティ確認、公式サイト側テンプレートとのCSS競合確認が必要です。
